# GTEki kit library — provenance and rights

Status: kit `0.1.0`, contract `gteki-asset/0.1`. Covers every file under `assets/library/`.

**Not used anywhere:** operator station maps or diagrams, operator photographs, Wikimedia or other photographs, PLATEAU / GIS geometry, brand marks, operator typefaces, JIS/ISO pictogram artwork, commercial game assets, Poly Haven or other downloaded materials. Sign faces contain only colour fields and simple geometric arrows; real wording is supplied at runtime by station leads. The one exception is the toilet entrance sign (`toilet_entrance`, batch P1). It carries a male, female, unisex or accessible figure that is hand-built signed-distance geometry in `tools/blender/gteki_assets/families/facilities.py`. ISO 7001 and JIS Z8210 are stylistic references only, and no pictogram artwork was traced or imported. The director approved this under the Owner's delegation on 2026-10-22 ([#151](https://github.com/nurockplayer/gteki/pull/151)); the rule is in [style.md](../../docs/assets/style.md) §6.

## Dimensions

Geometry uses either `generic-typical` dimensions (widely published typical/standard values: e.g. riser ≤ 160 mm / tread 300 mm stairs, 30° escalators with S1000/S600 step widths, ~0.6 m standard and ~0.9 m wide fare-gate aisles, 300 mm tactile blocks with the JIS T 9251 dot/bar layout family) or `synthetic` look-dev values. Every GLB records its basis in `extras.gteki.dimension_basis` and every parameter in `extras.gteki.params`. **No asset is a measurement of a specific station.** A station lead who rebuilds a variant with sourced measurements must record that evidence in their own station lane before labelling it `station-verified`.

## Licence

Decided by the Owner in Issue #123 (2026-10-22):

| Material | Licence | Where it is mapped |
| --- | --- | --- |
| Geometry and procedural textures (all GLBs, full and mobile), manifests, this note | **CC BY 4.0**, attribution "GTEki contributors" | `REUSE.toml` (`assets/library/**`), root `NOTICE` |
| Poster images `source/posters/poster_0[1-8].jpg` (AI-generated) | **CC0 1.0** | `REUSE.toml`, `NOTICE`, the sidecar below |
| 2D art batch 1 `source/art2d/**` and the contact sheet `docs/assets/img/art2d_batch1.jpg` (AI-generated) | **CC0 1.0** | `REUSE.toml` (after the CC BY block, so it overrides it), `NOTICE`, `source/art2d/provenance.json` |
| Code that builds the library (`tools/blender/**`) | Apache-2.0 (repository default) | root `LICENSE` |

Every AI image keeps its provenance sidecar, is labelled AI-generated, and shows no real brand, logo or trademark. Third-party material is not part of this library (see "Not used anywhere" above) and is never relicensed by these grants.

**Poster sidecar format** (`source/posters/provenance.json`, one object per image): `file`, `theme`, `prompt`, `generator`, `generated_at`, `width`, `height`, `sha256`, `notes`, plus the rights fields `license_spdx` (`CC0-1.0`), `ai_generated` (`true`) and `brands` (`none (fictional only)`). No build step reads or hashes this file: the GLBs embed the JPEG pixels, not the JSON, so adding the rights fields changes no asset byte. A new AI image adds its own entry with the same fields.

**Machine-readable rights in the GLBs.** The 96 committed GLBs (48 full, 48 mobile) and both manifests still say `license: "UNDECIDED — original GTEki work; repository licence pending Owner decision"`, because that string is embedded in the GLB bytes and `build.sh repro` compares rebuilds byte-for-byte with the committed library. The contract now defines `rights_class: "original"`, `license_spdx` (`CC-BY-4.0`, or `CC-BY-4.0 AND CC0-1.0` for a poster light box), and `attribution`, behind one switch, `contract.EMBED_SPDX` (off). The next full library rebuild (the AO rollout) turns it on and commits regenerated GLBs, manifests and hashes together. Until then the `UNDECIDED` string in an old GLB is a stale marker, not a restriction: the decision above governs. Details: [asset-contract.md](../../docs/assets/asset-contract.md) §3.

What the record supports, and what it does not:

- **Geometry and procedural textures** are produced entirely by the code in this repository from catalog parameters; no external file is read.
- **Poster images** are AI-generated. The record is limited to the prompts, generation date, SHA-256 hashes (`source/posters/provenance.json`) and our visual screening (no text, logos, marks or identifiable places were seen). That screening is not a legal clearance of the image provider's terms, which were not independently re-verified for release. Swapping the posters is cheap: `poster_lightbox` takes any repo-relative `poster_image` path, and the GLBs rebuild with `build.sh`. A supplied `poster_image` must come with `poster_provenance` and `poster_license` params, which replace the kit's claim in that GLB's `extras.gteki` and its manifest entry.

## 2D art batch 1 (`source/art2d/`)

31 Owner-approved AI images (2026-10-22): light-box and poster art, manners posters, a bathhouse mural, one glass-art panel, comics and guide-cat/dog sheets. `source/art2d/catalog.json` tells a station lead which image fits which slot; the cat and dog are assets only, not the official mascot (pending a similarity and trademark check). Look direction: [style.md](../../docs/assets/style.md) §10.

- **Generator:** Codex built-in image generation (embedded C2PA: ChatGPT gpt-image, OpenAI Media Service API). Four images were fixed with the same tool's image edit (blank paper strips, removed stray letters, hands on the handrail); the sidecar `edit` field records it. The raw PNGs are not committed.
- **Text layer:** the AI never draws text. Copy is typeset afterwards with ImageMagick by `tools/blender/art2d/typeset.py`, so every `typeset` line in `provenance.json` is the exact text on the image. Fictional brands only (for example みどり堂, アクアテラス).
- **Font:** Noto Sans JP Regular and Bold, `notofonts/noto-cjk` tag Sans2.004, commit 523d033, SIL OFL 1.1. The font is not committed; only rendered glyphs are in the images.
- **Licence:** CC0 1.0 (Owner decision, Issue #123), mapped in `REUSE.toml`. No third-party material is included, so nothing is relicensed.
- **Screening:** each image was visually inspected (at 100 % where paper strips or lanterns appear) for AI-drawn text, logos, real brands, real landmarks and photoreal faces; the per-image note is the sidecar `review`. This is not a legal clearance of the image provider's terms or of character similarity.
- **Source of record:** the shipped JPEGs (long edge 1024 px, sRGB, quality 85, metadata stripped). Generation is not reproducible bit-for-bit; `shipped` in `provenance.json` holds each JPEG's size and SHA-256, and `sha256`/`bytes` are those of the raw PNG.
- **Owner exception:** `s10_sento_mural` shows a snow-capped volcano in a bathhouse mural, accepted by the Owner as Mt Fuji (2026-10-22). It is the only real landmark in the batch.

## Regeneration

`tools/blender/build.sh` rebuilds all GLBs and `manifest.json` from the catalog; `tools/blender/build.sh repro` checks two clean builds are byte-identical.

`assets/library/mobile/` is the same catalog built with `PROFILE=mobile tools/blender/build.sh` (`PROFILE=mobile … repro` checks it). It comes from the same inputs as the full library and adds none. Its palette texture holds averages of the same procedural textures; its sign faces and posters are re-encoded copies of the same images. The rights above apply unchanged (CC BY 4.0 for geometry and textures, CC0 1.0 for the re-encoded poster copies).

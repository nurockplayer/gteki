# Freshness checklist for the research docs

What this is: a list of facts and decisions in `docs/research/` that can go stale (dates, planned changes, closures, drafts, dataset versions, snapshots, revision labels). It was built from every file under `docs/research/` on main plus the open branches for OD-22..30, R10, R11 and R13. Checked as of 2026-10-22. Facts only; no source text is copied.

How to use it:
1. Data research (data-research-61) re-reads the source when the row is due (a date, an interval, or the trigger named in the row).
2. Update the research file named in the row (add the new fact, the retrieval date and the source id).
3. Notify the lane in the last column; the station or GIS lane updates its own data, data research does not edit lane data.
4. Move the due date forward by the stated interval, or close the row when the trigger has fired and nothing more is planned.

A planned date is a plan, not a fact. Rows with an interval are due on the date shown, then again after the interval. Rows without a date are event triggers and are listed last.

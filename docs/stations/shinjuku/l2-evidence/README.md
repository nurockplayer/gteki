- The (B) prefix replay (E6) is partly reported (4 of 8 shards green); the other four shards and every post-merge result are pending, and no row below claims them.
- Credit/image-review note for future committed stills (like Ikebukuro's) is described, not yet written as a section.
- Perf rows E16–E20 are not reconciled with each other (E20 is older and inconsistent with E16).

- **Basis.** Index written at Lane B base `e31588b` (head of draft PR [#61](https://github.com/nurockplayer/gteki/pull/61), still open when reconciled); main `2e08516` for the original audit. Issues read on 2026-10-22 (newest #61 comment read 07:22Z; (B) figures from [#5 handoff r14](https://github.com/nurockplayer/gteki/issues/5#issuecomment-6335041712), 07:14Z).
- **Fixed on a branch is not on main.** Section 1.7 lists seven unmerged branches. Nothing in it is verified on main, and no row there is a PASS. Evidence for them is the branch's own tests and docs as reported by Lane B (r14); it was not re-run here. `gh pr list` showed no PR for any of them on 2026-10-22.
- **Reported, not re-run.** Test counts and run results below are as reported by Lane B (#61, #5) or Lane F (#61, #12, #5). They were not re-run for this index. Where a result lives only on a host (for example Lane F's `gteki-qa-evidence/b511263/`), it is marked "host-local, not linkable".

Any image or video of this scene is a render of GTEki-processed data: E27 「歩行空間ネットワークデータ（都営地下鉄大江戸線 新宿駅）」「構内地図データ（都営地下鉄大江戸線 新宿駅）」（国土交通省）を加工して作成, and PLATEAU 新宿区 (国土交通省 Project PLATEAU) を加工して作成. Owner visual-material rules from [#165](https://github.com/nurockplayer/gteki/issues/165#issuecomment-6335071234) apply to anything new: third-party photos are look reference only (OD-08), nothing CC BY-SA ships (OD-09), Mapillary is reference only (OD-11), Poly Haven / ambientCG CC0 only through Lane E with per-file provenance (OD-12), Owner photos ship as CC BY 4.0 credited to GTEki contributors (OD-13), and photos with operator logos or ads do not ship unless those regions are removed or blurred (OD-14); see `../l2-readiness.md`. Evidence images committed in future need a credit note beside them, as Ikebukuro's `stations/ikebukuro/docs/evidence/README.md` has (on main).
- **Structure.** Ikebukuro keeps committed stills and two videos with a credit and image-review note (`stations/ikebukuro/docs/evidence/`), and since #142 proves G1/G2/G0 rows with tests (`scene/frame.test.ts`, `scene/routing.test.ts`, `pipeline/audit_assets.ts`).

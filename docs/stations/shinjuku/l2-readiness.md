| Status | Meaning here |
| --- | --- |

### Navigation freshness (G2-1): GAP

**What is known.**
- The E27 files in use are the ほこナビDP resources, dataset page last modified **2026-09-17**, with link `maint_date` **2025-09-19** (`stations/shinjuku/sources/manifest.json`, `station.json` `datasetDate`, `coverage.freshness: "2025-09-19"`). The raw files were acquired 2026-10-20 (`acquiredAt`).
- The router's staleness rule is date-based: a route is stale when a source date is more than `staleAfterDays` old (default 730, `packages/navigation/src/index.ts:42`). With the dataset date of 2026-09-17, no route is flagged stale today, so the stale flag **cannot** detect the changes below.
- Related official facts that predate the E27 snapshot: exit 2 closed since 2024-03-30 (see G2-3). They are not a freshness gap, because `maint_date` 2025-09-19 is after them; whether E27 omitted a closed exit is not stated by any source.
- Public changes around the 新宿 West Exit plaza, dated after the 2025-09 snapshot, are listed in Lane D's research PR [#174](https://github.com/nurockplayer/gteki/pull/174) (`docs/research/gaps/DR-changes-since-2023.md` on main, rows CH-SJ-01..19). It lists: ground flow changed 2025-09-27 (CH-SJ-10); ground passages changed 2026-02-17 (CH-SJ-11); B1 passages changed 2026-04-07 (CH-SJ-12); stair 11 closed and a temporary stair opened 2026-06-23 (CH-SJ-13); road works planned 2026-10 to 2027-02 (CH-SJ-14, not underground). Earlier changes: West Exit stairs 1 and 2 closed 2023-10/11 (CH-SJ-01), the B1 north passage closed 2023-11-10 (CH-SJ-02), elevator B abolished 2023-09-30 (CH-SJ-03), and passage switches in 2024-11 (CH-SJ-07, -08).
- That PR's own conclusion: whether the E27 files reflect any of these changes is not established by any source it read.

**What is unknown.**
- Whether E27 (2025-09-19) already reflects the changes before it, and whether it omits those after it.
- Which E27 exit or passage each notice refers to. The notices use the operators' West Exit numbering and none maps to E27 exit numbers (`gap:exit-numbers`).
- Whether any E27 route passes through an affected stair, lift or passage. No such route is known; none is ruled out.

**What the app says today.**
- The public explorer (`apps/web`) shows a banner: 「公開データ由来・現地未確認を含む」 / "From open data; parts not field-verified" (`apps/web/src/i18n.ts:61,134`). Every route shows 「営業時間 未確認」. `coverage.freshness` and the source dates are carried in the contract.
- The sentence 「実際の移動案内を保証しません」 exists only in the footer of the lane dev app (`stations/shinjuku/app/index.html:79`), which is not a release surface. The README states "no real-world navigation guarantee". There is no statement in the public app that routes may predate the 2025-09 snapshot changes.

**What would close it.** Either (a) a per-change check of CH-SJ-01..14 against the E27 geometry and links, done by the data lane with a cited public source for each, recording for each change "reflected", "not reflected" or "not applicable to E27 extent"; or (b) a newer E27 release from the provider that post-dates the changes, imported through the existing importer. Until then this stays GAP. No routing is changed by this audit.

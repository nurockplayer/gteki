## Mid-range phone and throttle

[Chrome DevTools calibration documentation](https://developer.chrome.com/docs/devtools/settings/throttling) recommends host-calibrated low/mid-tier presets. [DevTools' calibration implementation](https://github.com/ChromeDevTools/devtools-frontend/blob/main/front_end/panels/mobile_throttling/CalibrationController.ts) defines mid-tier as Pixel 5-like with Lighthouse BenchmarkIndex 1000, and low-tier as score 264. It uses a string-allocation plus array-copy CPU benchmark and bisects the host slowdown rate; the runner reproduces that calculation and records all samples in `calibration.json`.

A fixed 4× multiplier is relative to this Mac; it does not independently establish phone equivalence. The numeric recommendation and limitations will be written after calibration. CPU emulation retains the M2 Pro GPU and cannot establish J12 PASS on actual phone hardware.

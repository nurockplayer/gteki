# Original rejected department-store interior frames

2026-11-23 JST: superseded by the [fixed blocker frames, measurements and replay](fixed/README.md). The following records the original rejected candidate.

2026-11-23 JST. Runtime candidate: `88577bacf15d2cfc09f87e39622499f74daa8025`. Capture timestamps in `receipt.json` use UTC (`Z`). Desktop 1440×900 and phone 390×844, DPR 1, existing walk camera, `?station=ikebukuro&next=1`; flag-off frames omit `next`. The existing minimap is collapsed through its UI. Search was exercised before capture; guidance/search are closed for the walk frames. No scene objects or lighting were changed by capture.

The walk uses the player collision controller from the station concourse, through B1, around the counter aisles, up the store escalator, across 1F and out the street door. Both profiles complete all 12 legs (including the extra wayfinding context and return), both search queries find the B1 destination, and every frame has zero shader errors.

The phone entrance-context frame turns the walk camera to show the entire existing wayfinding face beside the store band. `*-measurement-rois.jpg` marks the station face red and the store band blue; original PNGs have no annotations. Linear sRGB luminance is averaged inside the projected face polygons. Board/wayfinding: 0.423 desktop / 0.353 phone. The counter label's median background versus ink-core (0.5th percentile) contrast is 8.42:1 / 7.16:1; specified albedo contrast is 10.63:1. Street-door clipping counts any channel equal to 255 in the projected opening: 0% both. The nearest 0.15 m ja cap projects to 21.52 / 16.12 px. These are camera/pixel measurements; AD visual acceptance remains required.

The scene allocates 13 visual batches per floor including the paired escalator; the far landing adds one while riding. One 1024² board atlas, one 64² interim pool texture, instanced repeated pieces and no new real-time lights. The existing global environment is reused. Foreground J12 GPU performance remains for the art director to measure: CDP natural-frame sampling was throttled to approximately 1 Hz with most time idle, including after focus emulation. Neither the canonical `pnpm measure:gpu-fps` command nor a valid interior foreground GPU measurement ran here.

Frames: entrance-before, entrance-context, entrance-inside, food-hall-aisle, counter, escalator-boarding, arrival-1F, wide-1F, street-door-inside, street-door-outside, flag-off. The flag-off frame repeats the entrance pose using the unchanged base scene.

# G-5 performance

Frame time and GPU cost of the G-5b evidence poses. Each run below is a windowed capture by
`packages/godot/hq/hq_capture.gd --capture --perf`; this table is written from those `report.json` files by
`tests/perf_report.gd`. Every figure is the report's own: nothing here is estimated, and a run captured
without `--perf` says so instead of showing zeroes.

- **Frame interval ms** — the wall-clock gap between consecutive rendered frames, so vsync, the presenter and the compositor are in it.
- **Renderer setup ms** — `RenderingServer.get_frame_setup_time_cpu()`: the CPU time the renderer spent setting up that frame.
- `Performance.TIME_PROCESS` is not a per-frame figure (the engine refreshes it about once a second, with the largest process time seen in that second), so it is reported per run as one interval maximum, never as percentiles.

Measured on Apple M2 Pro (Apple8) (forward_plus via metal, macOS 27.0.0, Apple M2 Pro) in the lead's GPU slot.
